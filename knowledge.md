# Your project's knowledge

This app needs to be usable by kids in elementary school and their teachers. 

## Kids
Upon landing on the homepage, kids start to solve the exercises they are presented with. Kids answer exercises either
by directly typing the answer, or by clicking on one of the proposed results.

## Teachers
Teachers can create test parameters in the settings page. The test parameters are sets composed of elements that specify 
the following: 
- min/max range for the first operand,
- min/max range for the second operand,
- group of one or more operations that makes up the set from which the operations are shown in the homepage,
- number of clickable results to show.  

## UI

- Text needs to be clearly distinguishable from its background at all times and independently of the theme.
- The UI is based on the Catppuccin theme. It follows the user's desktop UI theme by default, but can be overridden in the settings to either dark (Catppuccin-Mocha) or light (Catppuccin-Latte).
- UI elements should be clean and simple, so kids can easily identify what certain elements are supposed to do.
